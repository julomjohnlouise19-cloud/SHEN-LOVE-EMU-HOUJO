# Science video collection

Use **Study Room → Science videos**. There are 50 distinct links, ten in each category. Search combines words with the selected category; six-card pages keep phone loading small. The exact linked video supplies its own thumbnail. **Watch here** deliberately loads the privacy-enhanced player; **Original video** opens the creator’s page. Related lab notes include supporting publications and a focus timer.

No YouTube API key, Google login or database update is required. This searches the curated collection, not all of YouTube. Videos and covers need internet and are not included in the offline cache. Missing covers use a themed fallback; unavailable embeds retain the direct video link.

Labels below describe topics, rather than promising exact creator titles. Learning prompts are lab-authored, not transcripts. Proposed Moon/Mars habitats are identified as engineering concepts. Use the related notes and their independent sources when checking scientific claims.
